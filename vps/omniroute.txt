更新版本
停止当前运行的服务
pm2 stop omniroute

通过 npm 覆盖安装最新版
npm install -g omniroute@latest

重新绑定 Playwright 浏览器
cd /home/ubuntu/.nvm/versions/node/v22.23.1/lib/node_modules/omniroute
npx playwright install chromium

重启服务并刷新环境变量
pm2 restart omniroute --update-env


卸载
停止并移除 PM2 进程
pm2 delete omniroute
pm2 save  # 这一步是保存当前 PM2 的空列表，防止服务器重启后它又冒出来

卸载 OmniRoute 全局程序
npm uninstall -g omniroute

清理数百兆的浏览器缓存
rm -rf /home/ubuntu/.cache/ms-playwright

清理软件运行产生的数据
rm -rf /home/ubuntu/.omniroute

把上面四步连起来
pm2 delete omniroute && pm2 save && npm uninstall -g omniroute && rm -rf ~/.cache/ms-playwright ~/.omniroute

清理 PM2 留下的运行日志
rm -rf /home/ubuntu/.pm2/logs/omniroute-*

自动回收无用依赖
sudo apt autoremove --purge
